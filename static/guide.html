USER GUIDE

本地环境归趋模拟

这是基于公开 SimpleBox 4.04 工作簿开发的独立网页实现。运行后所有计算在本机完成，不调用官方云服务，也不需要打开 Excel。

开始使用

  1. 在 Chemical Substance 中搜索完整物质名称或 CAS，从建议列表选择。库中包含默认物质和 3,993 种 PFAS。
  2. 等待属性加载。物质切换会按原工作簿计算理化属性；缺失数据可能沿用原模型默认值或估算规则。可修改全部 12 个公开数值属性。
  3. 设置各尺度排放，单位为 t/yr（吨/年），并选择环境情景。场景选择会更新该场景的排放和环境参数。
  4. 执行任一模拟。结果可按尺度查看，下载 CSV、Excel、JSON 或包含本次输入的完整模型。
  5. 保存情景会下载 JSON 文件；导入情景可恢复参数。Clear Input 将恢复默认物质、默认场景和初始参数。

五组计算功能

功能本地实现
Steady-State Simulation以原工作簿重算的 33×33 传输矩阵 K、排放 E 求解 M = −K⁻¹E。显示 33 个箱体的质量、浓度、逸度、排放、介质间通量与质量平衡残差。
Dynamic Simulation求解 dM/dt = KM + E。网页使用零初始质量、恒定排放，输出 201 个时间点。使用矩阵指数积分，支持质量与浓度曲线。逸度列为稳态参考值。
Fate FactorsFF = −K⁻¹ / 86400，单位为 day。矩阵列为排放箱体，行为接收箱体。总列和表示单位排放在所有箱体的总停留时间。
Compare Chemicals同一环境和排放下比较 1–50 个物质。每个物质从原库重新解析自身属性，不继承主表中对另一物质的手动性质修改。支持总质量、持久性和各箱体质量对比。
Sensitivity Exploration手动添加/删除情景行，导入 CSV、下载模板，或按某个属性生成均匀扫描。支持 1–50 行，每一行重算，失败行保留原因，不会以零掩盖错误。

单位与参数

输入分子量为 g/mol，温度为 °C，排放为 t/yr，面积为 km²，降水和侵蚀为 mm/yr，降解速率为 s⁻¹。工作簿内部会换算至 mol、m、s。输出质量为 kg，浓度为 kg/m³，逸度为 Pa，通量为 kg/yr。水中 1 kg/m³ 等于 1000 mg/L。

沿用原工作簿每年 365 天、摄氏温度加 273 的换算约定。土地/水域比例须接近 1，允许 1% 误差，以保留上游预设中的舍入偏差。负 pKa 和低于 0 °C 的温度允许输入；非有限值、负排放等会被拒绝。

方法、差异与限制

  • 不能宣称与官方服务器完全一致。公开仓库只含工作簿，未发布网页后端。本地实现复现已观察到的五组功能及输入，但界面、算法实现细节和输出格式并非官方代码。公开服务的所有结果尚未逐项对照。
  • 湖水排放修复：上游 engine!E5、N5 写死为 0，导致 input 页的区域/洲际湖水排放不参与计算。本地在每次运行的临时副本中将其连接到 E.w0R、E.w0C。这个修复在零湖水排放默认情景下不改变结果。
  • 原始辅助错误保留：默认情景 engine 页有两处 #DIV/0!，formulas 页有 121 处 #NAME?。本地不修改这些辅助公式；核心矩阵、体积、质量数值及质量平衡另行检查。若关键数据无效，计算会报错。
  • PFAS 数据质量：并非所有物质都有完整性质数据；数据库分类文本也可能与模型内置分类不完全一致。本地遵循原工作簿行为，不默默重写其科学假设。切换物质得到数值输出，并不等于该物质参数已经验证。
  • 动态与归趋因子：是对公开稳态矩阵的数学扩展，未使用已停止支持的 Rexcel 宏，也未声称复现官方未公开的求解器、默认初态或因子定义细节。
  • 持久性：这里计算所有箱体总质量除以总排放速率，转为 day。零排放时此指标显示为不可用。
  • 原始仓库与之前的 Excel 工作副本不被网页修改。每个计算使用独立临时文件，结果缓存在 runtime/cache。更改输入后网页保留上一次结果并标明结果已过期。

本地运行

双击项目根目录的“启动本地网页.command”。服务仅监听 127.0.0.1:8765。双击“停止本地网页.command”停止后台服务。终端运行：

.venv/bin/python server.py
# 或指定端口
.venv/bin/python server.py --port 8766

依赖 Python、NumPy、SciPy、openpyxl 与本地 LibreOffice。此电脑已配置完成；移至其他电脑需安装依赖。无需云端账户、API Key 或持续联网。
